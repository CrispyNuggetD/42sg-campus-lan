Your campus HQ, in one terminal.

Find your people, play a round, or send a file with a little uwu. A student-built project by Christopher Nah (hnah), for 42 Singapore. Start as a guest; sign in when you want verified campus features.

You need Git, Python 3.9+ and a terminal. Install tmux for the tabbed workspace. Linux and macOS are supported; campus features need access to the campus network and a configured API host.

Clone · set up · open

git clone https://github.com/CrispyNuggetD/42sg-campus-lan.git
cd 42sg-campus-lan
sh setup.sh
./lan42.sh

Try /games or /help. For API-reported cluster occupancy, Singapore students can /signin, then /clusters or /clusters 2—only while an approved host is running on campus (currently hnah’s). Installing or pulling LAN42 alone does not provide that service. Guest chat/games remain available when the host is offline. Stable, always-on hosting is future work. No student API key is needed to join the configured host.

Your browser. Your choice.

Set up faster: /setup or /allow batch lists categories with y/n choices. Type all during setup, or use /allow all, to allow the whole list after one confirmation. File receives, group joins and broadcast approvals remain separate.

One browser approval covers inherited browser pages for this LAN42 session. Game terminals and ordinary desktop notices have separate permissions. Important host, broadcast, release and offline-warning alerts default to on; explicit notification denial still blocks them. Chat, DMs and pokes default to off. /notify lists channels; /notify all off silences everything. Enter means No. Type y then Enter to allow this action.

01

Find your people

Your HQ stays open while you connect to friends.

/join c1r2s3

Link a friend’s LAN42 node at that seat.

/who · /roster

See connected LAN42 users.

/clusters · /c1 · /c2

Open the separate LAN42 clusters window for API-reported seats. In that window, r or Enter refreshes from the host and the header shows snapshot age. /settings clusters-auto-open on can open it with HQ.

/locate thtay

In the clusters window, find the reported seat for a login. HQ can still highlight its LAN42 peers.

/profile

Open your personal signed-in Intra home.

/profile thtay hnah

Request two public Intra profile tabs.

/next · /prev

Page through maps and rosters.

02

Friends, mutuals & lists

Your relationship labels and lists stay on your computer.

/track dthoo thtay

Add acquaintances. /track shows your current setup.

/track friends dthoo

Promote a friend; arrivals get a warmer message.

/track status moots thtay

Set mutuals (moots). oomf is another relationship label.

/track list lunch add dthoo thtay

Create or add to an independent list called @lunch.

/track list lunch remove thtay

Remove a list member. Use delete to remove the list.

/untrack dthoo · /untrack all

Stop personal tracking; custom lists remain independent.

/track config · /track help

Find the private JSON file or full terminal guide.

03

Lunch plans & private messages

You type the message and press Enter to send.

/dm dthoo "want lunch?"

Send a direct message to one reachable user.

/dm friends "do you all want lunch?"

Send one individual DM per selected friend.

/dm @lunch "meet at noon?"

Use a custom list as the recipient selector.

/alert mutuals "game later?"

An alias for targeted DMs and desktop notifications.

/compose

Restore a waiting notification-action draft after finishing your input.

04

Arrival rules, separately

Campus checks run every five minutes while HQ is open. LAN42 arrivals use lobby updates.

/settings clusters include cohort4 c1

Subscribe to cohort4 arrivals in Cluster 1. C1/cluster1 also work.

/settings clusters exclude some-login

Exclude someone from the separate arrival rules.

/settings clusters c1

Limit rule alerts to cluster 1. Use c2 or all; C1/cluster1 also work. Friends keep their own alerts.

/settings clusters on · off

Enable or pause these rules; personal friend tracking stays separate.

/settings clusters clear include

Clear includes; use exclude to clear exclusions.

/track alerts dthoo campus off

Mute personal campus alerts. Use lobby for LAN42 arrivals.

/notify off · /notify on

Mute or enable desktop notices; terminal history remains.

Optional running joke: off by default; once or always, with an Are you SURE? confirmation.

KoelDrop: files in your nest

The host starts a 42 Singapore flock. Join once, always join or never show again; receiving files stays separate. Local copies are kept on shutdown.

/koel flock once

Verified SG users on campus: join the public flock in a fresh folder after consent. Use always, never or ask to change future choices. /koel flock-dir PATH sets its service root. Existing folders are never imported or erased.

/koel create

The on-campus API host can also create a private invitation group after confirmation. No experimental flag is needed.

/koel invite dthoo

Invite a verified student in your trusted lobby. friends and @LIST also work.

/koel accept 1

Accept invitation 1 and start uploads from a dedicated folder. /koel decline 1 says no.

/koel pending

List incoming file offers. /koel receive 1 approves; /koel reject 1 declines.

/koel dir "EMPTY PATH"

Choose a dedicated folder; unrelated home folders are never scanned.

/koel leave

Stop group uploads and keep local copies. /koel sync syncs now.

/koel trust dthoo

Separately confirm automatic receives from this person in this group; deletions still ask.

Search with a little impact

Ecosia by default; Google or custom HTTPS engines in /settings search. Ecosia says all profits fund climate action.

/search your search terms

Opens your default browser with the chosen engine. Permanent aggregate reporting defaults on; /settings search counting off opts out. No query-history list, student identity or result tracking is retained.

/search stats

Host-recorded Ecosia launch total and estimated unique searches. These are usage figures, not verified completed searches or trees planted. Offline hosts never block opening a search.

Exam quiet: Wednesday 15–18 and every Saturday 13–16 SGT. LAN42 audio only; system output stays unchanged. The pinned host can add dated windows. /quiet status · /exams. Release popups coalesce for 30 minutes and are capped at one per 24 hours.

One little uwu

Sound is opt-in. Automatic calls stay off until enabled and play only on your computer.

/uwu

One short, 0.85-second koel call. Mac playback uses a native WAV copy with brief silence around the unchanged call. If sound is off, LAN42 asks first.

/uwu dthoo

A private two-second poke; the recipient controls notifications and audio.

/uwu auto

Random local calls every 10–15 minutes. This choice persists across HQ windows; /uwu off turns it off. Persistent sound requires /settings koel-sound always.

/volume

Toggle system output 0 ↔ 30%. /volume 65 sets it to 65% and matches your desktop slider.

/settings audio-auto-on off

Stop automatic unmuting. Muted uwu asks to raise output to 30%, then separately offers to remember that permission. /settings audio-startup-volume on separately sets output to 30% when HQ starts.

Relationships and lists

/track groups sorted names by relationship and named list. /track friends, /track mutuals, /track oomf and /track tracked display a group. Add logins or a list to assign a label: /track friends @furs. Friends selection includes mutuals and oomf. Labels stay local. Login targets require the private Singapore JSON or text whitelist; unknown names are rejected before adding or sending.

FORKNITE presence and meal timing

The campus header shows total/C1/C2 counts and source age in HQ and games. Missing data is unavailable; snapshots older than two minutes are stale. Existing SG sign-in or local-operator access is required. Counts come from the host’s one-minute campus crawl, independent of replay time.

/sabo online [COUNT] [cluster 1|2] uses Intra logins from the host’s last campus API crawl, including people who do not use LAN42. It reports snapshot age without refreshing; the approved host seeds it at startup and refreshes every minute. Retry /clusters if startup loading failed. /sabo verified [COUNT] selects active verified SG users connected to that host, regardless of campus presence. Both require the signed-in room host, exclude seated people, cap at free table seats and retain whitelist/profile checks. Nobody is contacted.

Purple highlights the last diner to start each meal wave at an odd table while that diner is eating. This normal extra turn is separate from an overdue wait. Lime/cyan/pink count meal starts. Orange marks an overdue wait or a meal that arrived late; the next on-time meal clears it. The estimated interval is max(eat + sleep, 2 × eat) for even tables, or max(eat + sleep, 3 × eat) for odd tables, plus max(2ms, 5% of eat) grace. Five diners at 100ms eat / 100ms sleep have a 305ms late threshold, not one eating slot. This is a display estimate; native C still controls death. Timing freezes when the round ends.

API-owner avatar batches

On the approved API operator computer, use /tool LOGIN... for explicit logins. For a long list, open /tool, paste whitespace-separated logins without the command prefix, then choose Cache all logins. This tool does not expand all or cohort selectors.

The private singapore.json whitelist is preferred; singapore_intra.txt is the fallback. Unknown names are skipped before API lookup. Missing photos, lookup errors and save failures are reported per login while the batch continues. The final report counts requested, skipped, failed and successful inputs; Download batch log saves the local report.

Install or reload the LAN42 avatar-saver Chrome extension. Version 1.3 closes completed batch photo tabs; failed saves stay open. Keep the admin terminal running for imports. Existing request budgets still apply. Student directories and reports stay local and must not be committed to public Git.

KoelDrop desktop shortcuts

KoelDrop is add-only: the host assigns names like report_dthoo_1.pdf. Edits and renames add copies; shared deletion is disabled. Upload limits: 6 additions/minute in shared locations, 30/minute in your own folder. F3 opens the separate campus-clusters window while HQ chat stays visible. Map legend: magenta friends, cyan list members, green signed-in users, yellow guests, blue API-only logins and dim unreported desks.

Ubuntu/GNOME startup separately asks about a dock launcher and a pinned location in the Files sidebar. Enter declines; existing pins/bookmarks skip their prompts. Use /koel dock or /koel bookmark to ask again. Both point to ~/KoelDrop. Flock files use 42-singapore/YYYY-MM-DD underneath, without hash or account folders; sharing consent stays separate.

File conflicts: HQ and permitted desktop alerts offer Keep both. Use /koel pending, then /koel resolve NUMBER. After confirmation, your copy is published under your member folder and the shared version is received at the original path.
