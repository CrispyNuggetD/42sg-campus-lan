zsh · LAN42 setup

Git, tmux, Python 3.9+ with curses; terminal ≥ 76 × 28. Setup backs up and appends to .zshrc.

Then open a new zsh terminal: lan42
Or launch directly: ./lan42.sh

02 / Choose your lane

You’re welcome
as a guest.

Guest

Chat and games work without the API host. /join connects you to a friend.

Signed in

Campus seats need an approved host running on campus (currently hnah’s), configured trust and verified SG sign-in. Click Sign in, press F2 or use /signin, then /clusters.

Cloning alone does not provide the campus API service.
